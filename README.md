# ✈️ AI Travel Planner

An AI-powered travel assistant that generates personalized itineraries using Large Language Models and Prompt Engineering.

## Features

- Zero-shot prompting
- Few-shot prompting
- Role-based prompting
- Groq LLM integration
- Dynamic itinerary generation
- Personalized travel recommendations

## Tech Stack

Python
Streamlit
Groq API
LLMs
Prompt Engineering
Environment Variables

## Architecture

User Input
↓
Prompt Template Selection
↓
Groq LLM
↓
AI Generated Itinerary

## Run Locally

git clone repository

pip install -r requirements.txt

streamlit run app.py
